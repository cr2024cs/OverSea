# 一、专题目标

帮助中国制造业企业评估泰国建厂地点，理解工业园区、土地使用、厂房租赁或建设、公用设施和相关审批事项。

# 二、主要机构

## 1. 泰国工业园区管理局 IEAT

Industrial Estate Authority of Thailand。

官方入口：
https://www.ieat.go.th/en

IEAT 负责工业园区相关管理和服务。工业园区通常提供道路、排水、污水处理、电力、供水及其他配套设施。

## 2. BOI / OSOS

BOI 的 One Start One Stop Investment Center 可提供投资及部分设厂手续方面的信息。

工厂建设许可说明：
https://osos.boi.go.th/en/how-to/145/Obtaining-Manufacturing-License/

# 三、泰国工业园区的基本概念

工业园区是为工业生产及相关经营活动划定的区域，可能提供：

- 工业用地；
- 标准厂房或定制厂房；
- 道路及物流设施；
- 供电；
- 供水；
- 污水处理；
- 排水及防洪设施；
- 园区管理和投资者服务。

不同园区的运营主体、土地权利、入园条件、产业定位和基础设施能力可能不同。

# 四、选址需要比较的因素

## 1. 供应链和客户

- 距离主要客户多远；
- 距离现有供应商多远；
- 是否方便从中国进口原材料和设备；
- 是否靠近港口、机场和高速公路；
- 是否适合产品出口。

## 2. 公用设施

- 供电容量；
- 电力稳定性；
- 供水能力；
- 工业用水质量；
- 污水处理能力；
- 天然气或其他能源供应；
- 通信和网络设施。

## 3. 土地和厂房

- 土地购买还是租赁；
- 土地用途是否允许目标生产活动；
- 厂房建筑面积；
- 层高和地面承重；
- 货车和集装箱通行条件；
- 消防和安全设施；
- 扩建空间；
- 土地权属和合同期限。

## 4. 环境和邻近条件

- 周边是否有居民区；
- 是否有环境敏感区域；
- 污染物处理能力；
- 是否存在洪水风险；
- 是否符合行业环境要求。

# 五、IEAT 园区土地使用

在 IEAT 管理的工业园区内开展业务，通常需要关注土地使用和经营活动许可。

相关资料：
https://www.ieat.go.th/en

IEAT 土地使用申请资料示例：
https://www.ieat.go.th/web-upload/1xff0d34e409a13ef56eea54c52a291126/202206/m_document/8350/16624/file_download/91c4ef652bccee87dc5562a27160ff10.pdf

政府投资指南还列出土地使用申请可能涉及：
- 公司股东资料；
- 园区总平面图；
- 土地权属或租赁文件；
- 环评文件（如适用）；
- 生产工艺资料；
- 其他主管机关要求的文件。

具体清单应按园区和项目核实。

# 六、AI 应重点追问的问题

- 工厂计划生产什么产品？
- 预计需要多少土地或厂房面积？
- 是购买土地、租赁土地，还是租赁现成厂房？
- 是否已有意向园区？
- 预计用电容量是多少？
- 是否需要大量工业用水？
- 是否产生废水、废气或危险废物？
- 是否需要特殊物流、冷链或危化品储存？
- 是否计划未来扩产？
- 主要客户和供应商位于哪里？

# 七、选址比较表建议字段

| 维度 | 需要收集的信息 |
|---|---|
| 地点 | 省份、城市、园区名称 |
| 土地 | 可用面积、购买/租赁、价格、权属 |
| 厂房 | 面积、层高、承重、交付状态 |
| 电力 | 可供容量、可靠性、费用 |
| 水务 | 供水能力、污水处理能力 |
| 物流 | 港口、机场、高速公路距离 |
| 环境 | 环评要求、排放限制 |
| 人力 | 招聘资源、交通、住宿 |
| 扩展 | 是否有扩建空间 |
| 服务 | 园区许可和投资者服务 |

# 八、常见风险

1. 只比较土地单价，忽略电力、污水和物流成本。
2. 土地用途与计划生产活动不匹配。
3. 只听取园区销售人员介绍，没有核实许可和基础设施。
4. 忽略租赁合同期限、续租、转租和提前终止条件。
5. 没有核查土地权属和抵押等情况。
6. 未考虑未来扩产和环保设施空间。
